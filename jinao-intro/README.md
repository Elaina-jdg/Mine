## 本地预览

- 最简单:直接双击 `index.html` 用浏览器打开。
- 或者在此目录运行一个静态服务器(命令见下文「部署」),访问 `http://localhost:端口`。

## 部署上线(像参考站一样有网址)

### 方案 A:腾讯云 CloudBase(和参考站同一个平台)

```bash
# 1. 安装 CLI(需要 Node.js)
npm install -g @cloudbase/cli

# 2. 登录(会弹出浏览器授权)
tcb login

# 3. 进入网站目录后一键部署静态托管
cd jinao-intro
tcb hosting deploy . -e <你的环境ID>
```

部署完会得到一个 `xxx.tcloudbaseapp.com` 的网址,和参考站一样。CloudBase 控制台里还能绑定自己的域名。免费额度够个人主页用。

### 方案 B:GitHub Pages(免费,适合新手)

1. 在 GitHub 新建仓库,把 `jinao-intro` 里的文件上传上去;
2. 仓库 Settings → Pages → Source 选 main 分支 / root;
3. 等 1 分钟,得到 `https://<用户名>.github.io/<仓库名>/`。

### 方案 C:Vercel / Netlify(拖拽上传,最快)

注册后直接把整个 `jinao-intro` 文件夹拖进网页,自动上线,还会给你 https 域名。

## 技术说明

- 单文件 HTML + CSS + 原生 JS,无框架、无外部 CDN,离线可用。
- 特性:日系手账风(奶油纸底/拍立得/便签/和纸胶带)、滚动渐显动画、二维码点击放大(lightbox)、进门页点歌仪式、右上角 BGM 圆钮。
- **三端适配**:手机(≤560px 单列紧凑版)、平板(≤900px Hero 单栏+两列便签)、PC(默认多栏宽版)各自断点调优;触屏设备自动加大点击热区,页面无横向滚动。
