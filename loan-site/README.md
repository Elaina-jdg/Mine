# 贷款计算器 · 网页版(Loan Calculator Web)

把 Java 控制台程序 **`App.java`** 的等额本息贷款计算逻辑,改造成一个可以直接在浏览器里使用的网站。
纯静态站点:**零依赖、无需构建、无外链 CDN**,离线也能用。

---

## 一、和原 Java 代码的对应关系

| 原 Java 程序 | 网页版 |
| --- | --- |
| `input.nextDouble()` 读取年利率 | 表单「年利率(%)」输入框 / 滑块 / 快捷标签 |
| `input.nextInt()` 读取年限 | 表单「贷款年限(年)」 |
| `input.nextDouble()` 读取贷款额 | 表单「贷款金额(元)」 |
| `monthlyInterestRate = annualInterestRate / 1200` | `calc.js` 中 `rate / 1200` |
| `monthlyPayment = loanAmount * monthlyInterestRate / (1 - 1/Math.pow(1+monthlyInterestRate, numberOfYears*12))` | `calc.js` 中同名公式(逐字对应) |
| `totalPayment = monthlyPayment * numberOfYears * 12` | 网页版按还款计划逐期求和(末期对齐,误差为 0) |
| `System.out.println("The monthly payment is $" + …)` | 结果卡片「每月月供」 |
| `System.out.println("The total payment is $" + …)` | 结果卡片「总还款额 / 其中利息」 |

**顺手修正的小问题**:变量拼写(`interst → interest`、`monthiy → monthly`)、月供输出漏掉的 `$` 符号。

**网页版新增**:零利率兼容(避免 `1/0` 除零)、输入校验与错误提示、实时计算、本金/利息占比环图、按年汇总 + 按月明细的还款计划表、CSV 导出、复制结果、响应式移动端适配。

## 三、本地运行

### 方式 1:直接双击(最简单)
直接打开 `index.html` 即可 —— 页面没有使用 ES Module,`file://` 协议下也能正常运行。

### 方式 2:起一个本地服务器(推荐,行为与线上一致)
```bash
cd loan-site
node serve.mjs 8420
# 浏览器访问 http://127.0.0.1:8420/
```

## 四、发布成真正的网站(任选其一)

该站点是纯静态文件,把 `index.html` / `styles.css` / `calc.js` / `app.js` 四个文件上传即可(`serve.mjs`、`README.md` 不必上传)。

| 平台 | 操作 |
| --- | --- |
| **GitHub Pages** | 新建仓库 → 上传 4 个文件 → Settings → Pages → Source 选 `main` 分支根目录 → 得到 `https://用户名.github.io/仓库名/` |
| **Netlify** | 打开 app.netlify.com → 把 `loan-site` 文件夹直接拖到 "Deploy manually" 区域 → 立即得到网址 |
| **Vercel / Cloudflare Pages** | 导入仓库 → 框架预设选 "Other / 静态站点" → 构建命令留空、输出目录留空或填根目录 |
| **任意虚拟主机 / 服务器** | 上传 4 个文件到网站根目录即可(或用 `node serve.mjs 80` 常驻) |

> 若希望网址更正式,可再绑定自己的域名(各平台均支持免费 HTTPS)。

## 五、计算口径与示例

- **月利率** = 年利率 ÷ 1200(年利率按百分数输入,如 `4.9` 表示 4.9%)
- **期数** = 贷款年限 × 12
- **月供** = 本金 × 月利率 ÷ (1 − 1 ÷ (1+月利率)^期数),全程固定
- **总还款额** = 月供 × 期数;**总利息** = 总还款额 − 本金

校验样例(可用来核对你的 Java 程序输出):

| 贷款金额 | 年利率 | 年限 | 每月月供 | 总还款额 | 总利息 |
| --- | --- | --- | --- | --- | --- |
| 100,000 元 | 5% | 30 年 | ¥536.82 | ¥193,255.78 | ¥93,255.78 |
| 500,000 元 | 4.9% | 20 年 | ¥3,272.22 | ¥785,332.86 | ¥285,332.86 |

> **取整口径说明**:本页与原 Java 程序一致 —— 总还款额按「未取整的月供 × 期数」计算(Java 只在打印时截断到分)。
> 银行实务中通常先把月供四舍五入到分,再 × 期数(上表第二行会得到 ¥785,332.80),两者相差几角钱,属正常口径差异。
>
> 结果仅供学习与估算参考,实际月供以银行 / 贷款机构合同为准。

## 六、本地自测(共 52 项断言,全部通过)

```bash
node test-calc.js     # 计算逻辑:与参考公式对照、计划表自洽、零利率与异常输入
node test-dom.js      # 页面行为:初始化渲染、按年/按月切换、快捷标签、输入联动、错误提示、重置
```

覆盖要点:
- 月供 536.82(10 万 / 5% / 30 年)、3272.22(50 万 / 4.9% / 20 年)与参考值一致;
- 逐期本金之和 = 贷款本金、逐期利息之和 = 总利息、末期剩余本金 = 0、每期还款额恒定;
- 零利率不除零、金额/年限/利率非法时给出中文错误提示;
- 还款计划「按年 20 行 / 按月 240 行」、标签高亮与提示文案正确。
